openclaw privacy policy

Effective 2026-11-08

openclaw is a private assistant operated by Etienne Deneault (edeneault@gmail.com) for personal use. It has one user, its owner, and is not offered to anyone else.

Google data

openclaw accesses only the Google data its owner authorizes on Google's consent screen. It asks for read-only access, for example to calendar events and to email metadata such as sender, subject and date, never email content. It uses that data only to provide the owner's own assistant features, such as daily summaries and alerts. It cannot send, change or delete anything in the owner's Google account.

Sharing

Google user data is never sold and never used for advertising. It is handled only by the service providers that run openclaw for its owner (cloud hosting, the messaging service that delivers the owner's messages, and an AI service), and only as far as each feature needs.

Storage and security

Data and credentials are kept in the owner's own cloud account, protected by access controls and encryption, and kept only as long as the features need them. Backups expire automatically.

Revoking access

The owner can revoke openclaw's access at any time at myaccount.google.com/permissions, and can delete the data openclaw has stored.

Google API Services User Data Policy

openclaw's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If openclaw's access to Google data or its use of that data changes, this page is updated first and its effective date changes with it.
